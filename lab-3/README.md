## Стан

  

Для кожного рядка таблиці дайте відповідь на три питання з кроку 3 Thinking in

React (§4.7):

  

1. Чи залишаються ці дані незмінними з часом? Якщо так, це не стан.

2. Чи передаються вони від батьківського компонента через пропси? Якщо так, це

   не стан.

3. Чи можна обчислити їх на основі наявного стану чи пропсів? Якщо так, це

   точно не стан.

  

| Дані                                           | Стан? | Чому |

| ---------------------------------------------- | ----- | ---- |

| меню: категорії й позиції (`menu`)             |ні     |Передається через пропси з data.js і не змінюється під час роботи інтерфейсу|

| текст у полі пошуку                            |так    |Змінюється користувачем із часом і не може бути обчислений з інших даних|

| значення прапорця «Лише в наявності»           |так    |Змінюється користувачем (кліком) і не може бути обчислене|

| позиції, що залишаться після фільтрування      |ні     |Може бути повністю обчислений на основі списку меню, тексту пошуку та оложення прапорця|

| кількість позицій у заголовку категорії, «(4)» |ні     |Обчислюється як довжина масиву позицій (category.items.length)|

  

Стан житиме в компоненті: App, бо він є найближчим спільним предком для SearchBar (який змінює та відображає значення стану) та MenuTable (який використовує ці значення для фільтрації списку).

export default function MenuItemRow({ item }) {

  return (

    <tr className={item.available ? 'item' : 'item unavailable'}>

      <th scope="row">

        {item.name}

        {!item.available && ' — немає'}

      </th>

      <td>{item.price} грн</td>

    </tr>

  )
